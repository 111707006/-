# FG STUDIO 正式網站：討論紀錄

2026-11-14 的品牌、風格、商業流程討論結果。詞彙定義見根目錄 `CONTEXT.md`。

**狀態：尚未開始製作。視覺風格與網站動畫規劃未定案，定案前不動工。**

## 已決定

### 品牌與定位

| 項目 | 決定 |
|---|---|
| 核心標語 | 「先理解你的品牌，再說好你的故事。」全站圍繞這句話 |
| 主要行動 | 申請品牌試做；過程中要建立信任 |
| 客群 | 品牌與學校、機構並重。音樂人不招攬，音樂影像只當實績 |
| 服務範圍 | 以溝通情境定義，不以「短影音」定義。包含學校的功能性影片、客服說明、工廠教育訓練等，不限對外宣傳 |
| 六種溝通情境 | 品牌介紹、產品說明、客服與常見問題、教育訓練、校園政策與活動、社群宣傳，全部列出 |
| 品牌架構 | FG STUDIO 是主品牌；GVS 是主推服務；VIP 是 GVS 的長期合約方案 |
| PPTG | 負責人的個人藝人名，不是重點，只出現在 Credits 與 About |
| 信仰 | 「For God／一切榮耀歸於神」移到 About 與頁尾，不放首屏 |

### 作品與實績

| 項目 | 決定 |
|---|---|
| 品牌區 | 不做。不以客戶為單位展示作品，避免顯露「只有這幾家合作」 |
| 素材庫 9 支影片 | 放在六種溝通情境旁當範例，只標情境、不標客戶名稱；另挑 3–4 支作為首屏的代表影片 |
| 展示原則 | 少量代表作呈現多樣性，不給訪客一堆影片 |
| 客戶 logo | 拿掉。只留 MTV、KKBOX、Netflix 三個播出與收錄標誌 |
| YouTube 作品 | 全部保留（含 Wedding day），放在下方，不是主角 |
| YouTube 排序 | 自動跟隨 YouTube 播放清單的順序 |
| GVS 形象影片 | 保留，改用自有影片檔，不用 YouTube 嵌入 |

| 項目 | 決定 |

## 未定案：視覺與動畫

以下是討論中提過的想法，**尚未決定**。

- **方向**：影片是主角，網頁本身的動畫也是主角，要讓人透過動畫感受到服務怎麼運作。
- **開場**：logo 的 FG 拆開成 For God，再進入首屏；約 1.3 秒，每次進站都播。現有 `fg.png` 可重畫成向量來做。
- **首屏構想**：早期想法是「地球 → 素材飛入 → 辦公室作業員 → 成品」的故事線。負責人已表示**不必維持這個設定**，首屏故事重新開放。
- **動畫份量**：曾選擇真 3D。參考網站拆解後發現喜歡的網站都沒用 3D（見 `reference-teardown.md`），傾向改為像素與復古電腦風。
- **最喜歡的參考**：The InnerWebs 與像素風；另有 Cut/Run、Dylan Landman、8 Seconds、Igloo Inc。
- **待決定**：整體視覺風格、品牌色、字體、動畫的實際分鏡。

### 目前方向（2026-11-15）

**水下世界**，以開源專案 [Abyssal Garden](https://github.com/Noniv/abyssal-garden)（MIT 授權）為基礎改造。原始碼研究見 `reference-teardown.md`。

- 水下擺放**復古電腦**，螢幕播放影片。
- **發光寶箱**用來放文章、聯絡我們等內容。
- 實作會在**有顯示卡的電腦**上進行。目前的雲端環境沒有顯示卡，無法執行或驗證畫面。（2026-11-15 更正：負責人的筆電有 GTX 1650，實測可以執行，見 `docs/spec.md` 第 6.0 節。）

2026-11-15 更新：負責人確認走這條路線，並實測原版在自己的 iPhone 上可以執行。上游專案已複製到 `abyssal-garden/`，完整實作規格見 `docs/spec.md`。

2026-11-15 再更新：負責人決定**自由探索**，不以依序瀏覽為唯一方式；電腦一到兩台，點擊後鏡頭轉到正面播放（參考 The InnerWebs 的老電腦）；寶箱可以多一些，舊站資訊都放進寶箱；用發光提示可點的位置。

尚未決定：「文章」的內容與來源、是否要環境音、不支援 WebGPU 的裝置（多數手機）看到什麼、配色。
