# 參考網站拆解

2026-11-14。拆解負責人最喜歡的三個參考網站，目的是學習手法，不是複製它們的美術或品牌。

**方法**：用無頭瀏覽器實際載入每個網站，桌機（1440×900）與手機（iPhone 13）各一次，邊捲動邊截圖，並記錄網路請求、載入的函式庫、字體、顏色、動畫名稱與頁面結構。

**限制**：只觀察了載入與捲動，沒有點擊互動元件；Dylan Landman 沒有操作角色走出第一個畫面；打包壓縮過的程式無法辨認的部分已標明。

## 1. The InnerWebs

### 敘事結構

頁面高約 8,400px，是一段從頭講到尾的故事：

1. **首屏**：點陣字標題「Maximize your ~~Productivity~~ SANITY」，旁邊一台老電腦，螢幕裡播放影片。背景是低對比的重複跑馬燈文字。
2. **提問**：「What the heck is The InnerWebs」。
3. **問題**：一連串 Win95 視窗隨捲動出現，**每個視窗只放一句話**（「You have an app for everything but it feels like work to do anything」）。中間穿插懷舊 GIF 與小型警告對話框（「…distracting」「…and exhausting」）當笑點。
4. **轉折**：「But there's a better way」。
5. **解答**：仍用視窗，一句一窗。
6. **評價**：「Real Reviews* ／ *Fake photos」，自嘲式的假照片評價。
7. **收尾**：畫面轉暗，列出「Less … ／ More …」對照，最後是按鈕與「12,499 People Currently Waiting」。

全站只有一個行動：「Reserve your spot」，固定在頂端，結尾再出現一次。

### 手法

- **映像管效果是純 CSS**。一層固定的全螢幕覆蓋層，由兩個漸層疊成：2px 高的水平掃描線，加 3px 寬的紅綠藍直條紋；透明度在 0.2 到 0.4 之間緩慢呼吸，另有兩條暗帶由上往下掃過。螢幕上下緣各有一層固定遮罩做出弧形邊角。使用者若設定減少動態，動畫會關閉。
- **真實影片放進復古外框**。老電腦是一張只有外殼的 PNG，螢幕位置放影片或 GIF。
- **會動的背景很輕**。背景是一支 800×448、不到 1 MB 的漸層循環影片，再加 8px 模糊。
- **字體分工**：點陣字用於首屏標題；窄體襯線字用於視窗裡的句子；手寫麥克筆字用於「SANITY」；另有 Comic Sans 等懷舊字體點綴。
- **顏色**：Win95 灰 `rgb(192,192,192)`、視窗白、黑、藍紫漸層、青綠、奶油色按鈕 `rgb(243,221,157)`。
- **動畫**：浮動、故障抖動、跑馬燈、邊框脈動等是 CSS 動畫。隨捲動出現的效果由 GSAP 與 ScrollTrigger 驅動（打包後的程式裡找得到，見文末 REA 一節）。程式裡另有拖曳事件處理，視窗可能可以拖動，未實測。

### 手機

同樣的內容直向堆疊，視窗撐滿寬度，映像管覆蓋層保留。運作正常。

### 可借用

- 外框復古、螢幕內容是真的。
- 一句一窗的節奏，強迫文案精簡。
- 映像管覆蓋層成本極低。
- 單一行動貫穿全頁。

### 不適用

- 自嘲與玩梗的文案語氣。
- 八種字體；中文字體檔很大，不可能照做。

## 2. Cut/Run

### 敘事結構

頁面高約 8,400px：

1. **首屏**：全螢幕作品集影片，中央是巨大的橘色「Cut/Run」，左右各一行小字標語（「We Cut The Creative. And We Run The Ads.」）。
2. **我們是誰**：往下捲時一整塊橘色由下往上蓋住影片，上面是一段短宣言，語氣刻意反對傳統代理商。
3. **作品**：編號段落 `[01]` `[02]` `[03]`。每張作品卡有分類標籤、「TAKE A LOOK」，**標題直接寫成果**（「Premier Homes — 500x Return」「Inviva — 10M+ Views」），下方列觀看數與製作時間（「1 wk production + 2 wks post」）。
4. **客戶 logo 列**：CBRE、JLL、Colliers 等。
5. **服務**：「Beyond the Screen」，手機外框裡播直式影片，旁邊是數字（國家 9、追蹤 +21,000、曝光 2,600,000）。
6. **引言**，然後聯絡：「Tell us what you're trying to shift」。

右下角全程固定一個 WhatsApp 按鈕。

### 手法

- **全站兩個顏色、一種字體**。橘 `#FF4500` 配近黑 `rgb(29,29,27)`，字體只有 Poppins，偶爾用 Georgia 斜體。記憶點來自克制。
- **影片全部自架、540p**。每支有封面圖，捲到才載入。首屏影片 5.5 MB。
- **捲動**：Lenis 平滑捲動，GSAP ScrollTrigger 驅動進場，SplitText 做逐字動畫。
- **小細節**：自訂游標；跑步剪刀吉祥物用逐格圖動畫；按鈕裡文字跑馬燈；雜訊紋理覆蓋；頂端導覽列有 40px 背景模糊；換頁用 Swup 做轉場。

### 手機

漢堡選單，作品卡單欄，WhatsApp 按鈕保留。運作正常。

### 可借用

- 一個品牌色貫穿全站。
- 作品標題寫成果而非片名。
- 直式影片放進手機外框展示。
- 常駐通訊按鈕（FG STUDIO 對應 LINE）。
- 540p 自架影片加封面圖、捲到才載入。倉庫裡的 `media-library/web` 與 `previews` 已是這種規格。

### 不適用

- 客戶 logo 列。FG STUDIO 已決定不顯露客戶數量。
- 成果數字。目前沒有可公開的觀看數或成效資料。

## 3. Dylan Landman

### 結構

沒有頁面捲動，頁面高度等於螢幕高度。訪客用 WASD 或方向鍵操作像素角色在場景裡走，點擊物件互動；內容（作品集、關於、履歷、聯絡）以彈出視窗呈現。

右上角有選單，可直接開啟 Portfolio、Map、Resume、操作說明。**不想玩的人靠這個選單也能看到內容。**

另有遊戲化元素：背包、可撿的道具、成就通知、釣魚圖鑑、小遊戲。

### 手法

- **沒有用 Canvas 或遊戲引擎**。場景是一般網頁元素加背景圖，用 `image-rendering: pixelated` 保持像素銳利。
- **角色是 28 張圖**：前後左右四個方向，每個方向 7 格，走路時輪流切換。
- **碰撞與遮擋自己寫**：Matter.js 加自製的碰撞引擎與前後層級管理。
- **介面用現成函式庫**：NES.css 提供 8-bit 風格的對話框與按鈕；字體是 Press Start 2P。
- **氣氛**：全螢幕的光影層與暗角層，用色彩相乘混合；雲朵飄動、營火閃爍。
- **彈出內容**在需要時才另外載入。

### 手機

畫面下方出現四個方向按鈕，點物件互動。

### 問題

- **極重**。載入時抓了 124 張圖共約 20 MB，以及 8 支 1080p 作品影片共約 254 MB，單支最大 63 MB。行動網路上不可行。
- **美術量大**。光角色就 28 張手繪圖，場景還有數十張圖塊。這不是程式能生成的。
- **內容藏在探索後面**。想看價格或聯絡方式的訪客得先學操作。

### 可借用

- 像素世界不需要遊戲引擎就做得出來。
- NES.css 與像素字體能快速建立一致的 8-bit 介面。
- 用光影層與暗角營造氣氛。
- 一定要有選單當捷徑。

### 不適用

- 以操作角色作為唯一瀏覽方式。FG STUDIO 的訪客是老闆與學校行政。
- 預先載入全部影片。

## 對 FG STUDIO 的結論

1. **不需要 3D**。三個最喜歡的網站都沒用，效果來自美術、排版與節奏。
2. **最適合的骨架是 The InnerWebs 的捲動敘事**：復古外框裡放真實影片，一句一窗。標語「先理解你的品牌，再說好你的故事」本身就是一個兩段式敘事，可直接對應「問題 → 轉折 → 解答」。
3. **用 Cut/Run 的克制**：一個品牌色、最少的字體、自架輕量影片、常駐 LINE 按鈕。
4. **像素遊戲的部分只取氣氛**：像素字體、8-bit 介面元件、像素場景作為首屏插畫；不做可操作角色，或只當彩蛋。
5. **精緻像素美術是真實成本**。Dylan Landman 的水準需要畫師。程式能畫的是簡潔幾何像素圖。
6. **中文字體是額外限制**。像素風中文字體選擇少、檔案大，需要另外評估。

## REA 補充分析

應負責人要求，另外用 REA（Reverse Engineer Anything，`rea-agents` 6.9.0）對三個網站各跑一次 `analyze-web-bundle`。REA 透過瀏覽器除錯連接埠擷取頁面載入的全部程式檔並做靜態分析。

| | The InnerWebs | Cut/Run | Dylan Landman |
|---|---|---|---|
| 擷取的程式檔 | 33 支，約 1.06 MB | 38 支，約 0.49 MB | 20 支，約 0.45 MB |
| 辨識出的框架 | Next.js（高信心）、React | 無 | 無 |
| 頁面路由 | `/`、`/faq` | 無 | 無 |
| 其他 | 圖片經 Next.js 圖片最佳化 | 觸控手勢用 Hammer | 彈出內容用 `$.get` 載入 HTML 片段；小遊戲分數存在 Cookie；彩帶特效是 Lottie 動畫 |
| 分析完整度 | 部分（一支程式逾時） | 部分 | 部分（一支程式逾時） |

**結論**：REA 的網站分析著重路由、API 端點與框架辨識，也就是「這個應用怎麼運作」，不處理版面、配色與動畫。對視覺參考而言，它確認了前面的技術判斷，沒有推翻任何一項。

唯一的新資訊來自直接搜尋 REA 擷取到的程式檔：The InnerWebs 的打包程式內含 GSAP 與 ScrollTrigger，補上了先前「無法確認動畫函式庫」的缺口。三個網站中有兩個用 GSAP 加 ScrollTrigger 做捲動動畫，這是 FG STUDIO 正式站最合理的選擇。
