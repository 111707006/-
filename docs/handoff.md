## 程式放在哪

| 檔案 | 內容 |
|---|---|
| `site/shader.js` | WGSL 全螢幕光線追蹤：方塊求交、椅子的距離場、磚、石材、發光玻璃、影片螢幕、工作站介面、格柵天花、地面反射、線光源與光暈、色調映射 |
| `site/main.js` | 場景資料（`boxes`、`lines`）、鏡頭路徑（`KEYS`）、影片圖集、捲動、開場、直式螢幕的鏡頭修正、HTML 標示的透視矩陣、畫質分級、解析度調整、靜態版本 |
| `site/index.html` | 版面、載入畫面、五站的說明、牆面與櫃檯上的 HTML 標示（`.wl`） |

要點：

- **材質編號**：0 磚、1 石材、2 發光玻璃、3 影片螢幕、4 大廳後牆、5 工作站螢幕、6 黑金屬、7 接待螢幕、8 大廳天花、9 地面、11 椅子。
- **方塊分兩段**：`nOuter` 之前是大件；之後是作業中心的長桌與螢幕，著色器先測視線有沒有穿過那一區（`OP0`／`OP1`），沒有就整段跳過。新增作業中心以外的方塊要放在 `const nOuter = boxes.length` 之前。
- **椅子不是方塊**：`shader.js` 的 `chairs()` 是距離場，六張椅子靠 x 方向的重複畫出來，只在 `CH0`／`CH1` 的範圍內步進。第四輪加了提早返回：離單張椅子的外框超過 0.08 就直接回傳到外框的距離。椅子的位置寫死在著色器裡（x = -4.5 + 1.8k，z ≈ -7.78），改長桌位置時要一起改。
- **uniform 開頭 28 個浮點數**（7 個 vec4）：鏡頭位置與時間、前向與 tan、右向與長寬比、上向與暖光亮度、解析度與方塊數與線光源數、站點與圖集參數、`ex`（x = `nOuter`、y = 玻璃亮度、**z = 畫質，1 高 0 低**）。`MAX_BOXES` 112、`MAX_LINES` 24。
- **座標**：中庭沿 z 軸，入口在 z=0，首頁鏡頭在 z=41 往 -z 看。左牆內面 x=-10，右牆 x=10。玻璃量體的範圍寫死在著色器的 `GMIN`／`GMAX`。
- **開場**：`tI` 是開場的秒數；暖光 0.3 秒起亮、玻璃 1.6 秒起亮、鏡頭 6 秒就定位（`introK`）；`introK > 0.82` 才顯示首頁標題。捲動時 `tI` 以五倍速走。
- **直式螢幕**：`tall` 是直式的程度。首頁少拍天空；第 1 站往左退、往右看；第 3 站退到門口並把水平視角放寬到 33°；第 4 站退後右移並收窄到 21°。都在 `frame()` 開頭那一段。
- **畫質分級**（第四輪）：
  - `trace()` 與 `shade()` 多一個 `lite` 參數。主視線一律 `false`；地面反射那一次傳 `lq`（低畫質時為真）。`lite` 的 `trace` 只測 `nOuter` 之前的大件、不畫椅子；`lite` 的 `shade` 不跑 `lighting()`，用一個固定的暗環境光。省下的主要是地面像素的第二次求交與逐燈光照。
  - `main.js`：手機（`navigator.userAgentData.mobile`，或 UA 含 Android／iPhone／iPad／Mobile）一開始就用低畫質；其他先用高畫質。解析度上限高畫質 1.5、低畫質 1.25。
  - 自動換低畫質：每 30 格檢查一次。高畫質時如果「慢」且解析度已降到 1 倍以下，或連兩次低於 30 幀，就換低畫質（解析度不變）。換了不會換回去。`?q=` 固定時不換。
- **解析度調整**：下限 0.45。`best` 是看過最短的每格時間；每格超過約 21.7 毫秒就降，貼著 `best` 就試著升，升了又掉回來的話下次等更久。降到下限還不到 20 幀、連續三次，就換靜態版本。
- **牆上的字**是 HTML，用與著色器同一台鏡頭算 `matrix3d`，沒有遮擋判斷。`data-stops` 限定只在哪幾站顯示：兩面牆的大字只在自己那一站，櫃檯的字在第 0、4 站。
- **重複的標題**：第 2、4 站的說明面板不顯示 `h2`（牆上已經有同名大字）；靜態版本沒有牆上的字，照常顯示。
- **工作站螢幕**的預覽窗取樣作品牆那六格圖集，所以播的是真的作品。
- 片段著色器裡依材質分支的地方只能用 `textureSampleLevel`，不能用 `textureSample`。
- 光沒有陰影，全部是解析式近似。
- `site/` 的三個檔是 CRLF 行尾。**不要用 `sed -i` 改它們**（會變成 LF，整個檔都算有改動）；用 Edit 工具，或用 Python 以 `newline=''` 讀寫（第四輪用的是後者，替換字串時要把 `\n` 換成 `\r\n`）。`docs/` 的檔是 LF。
