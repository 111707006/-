## 怎麼執行

```bash
cd site
npm install
npm run build        # 寫出 site/index.html（有進版本控制）
npm run build:dev    # 寫出 site/dev.html（沒進版本控制），多了 F（飛行）、B（基準測試）與 window.dev
```

Node.js 在 `C:\Program Files\nodejs`，Bash 工具裡要先 `export PATH="/c/Program Files/nodejs:$PATH"`。Python 在 `C:\Users\a0900\AppData\Local\Programs\Python\Python312\python.exe`，不在 PATH。

要用網頁伺服器開（影片從 `../media-library/` 載入）。`.claude/launch.json` 設定了一個叫 `site` 的伺服器（倉庫根目錄，**埠 8741**；原本的 8732 被另一個工作階段佔住），用內建瀏覽器的 `preview_start` 啟動，開 `http://localhost:8741/site/dev.html`。

### 兩種驗證方式

- **內建瀏覽器**（Claude 桌面應用程式的瀏覽器面板）：WebGPU 可用，但跑在內顯上而且很慢，載入約 25 秒，動畫時間會被拉長（開箱後要等好幾秒視窗才出現）。適合看樣子與流程，**效能數字不能用**。
- **獨立的 Chrome**（GTX 1650）：`docs/batch-3/cdp.py`（只靠 Python 標準函式庫的 CDP 小程式）會自己啟動 Chrome、拍一組截圖、跑兩次基準測試再關掉。用法：`python docs/batch-3/cdp.py docs/batch-3 http://localhost:8741/site/dev.html headless shots`（伺服器要先開著；`shots` 只拍截圖，`bench` 只跑基準測試，都不寫就兩個都做）。**一定要加 `headless`**：不加會跳出一個視窗搶走焦點，負責人正在用這台電腦時會點到它，截圖與數字都會被打亂（這次就發生了）。無視窗模式一樣用得到 GTX 1650。
- **物件有沒有被擋住要看獨立 Chrome 的截圖**：內建瀏覽器太慢，繪製距離被自動調低，珊瑚與海綿畫得少，看起來沒擋住的在快的顯示卡上可能被擋住。

`dev.html` 有 `window.dev`（在 `site/src/dev.js`）：`dev.turn(a)` 站在出生點往右轉 a 弧度、`dev.seen()` 每個物件從出生點看過去有沒有被岩石擋住（海帶與海綿不算，要看截圖）、`dev.activate(i)` 開啟第 i 個物件、`dev.visit(i)` 等於點潛水日誌的第 i 項、`dev.state()` 讀狀態。

用 Bash 的 heredoc 寫含有反引號與引號的大段程式會整個不執行。改用 Write 工具寫成檔案再執行。

要點：

- 物件的順序固定是 `IDS`：video、info、contact、plans、process、work、about。潛水日誌的 HTML、`BOXES`、`hot`、`activate(i)` 都用這個順序；寶箱的編號是它減 2。
- 出生點到每個物件的視線上，擋路的珊瑚與海綿會被清掉（`main.js` 建 `ibProp` 之前那一段，把大小設成 0；不動世界生成的亂數）。海帶與岩石不會清，所以位置還是要選開闊的地方。
- `LAY` 的每一筆是「從進站的方向往右轉的角度、距離、（寶箱）朝向的偏轉、光的等級」。要改位置就改它，然後用 `dev.turn()` 加截圖確認沒被擋住。
- `fxData` 的排列：先是每個寶箱的光柱，再來每個寶箱的光暈，最後每個寶箱 `NMOTE` 個光點。`b.z` 是光的等級（1 或 0.6），`b.w` 是目前的強度。
- 材質 7 把實例資料的 `c.z` 當成光的強度；箱體與箱蓋靠種子（0.61 與 0.23）分辨，不要改。
- 片段著色器裡不能在依材質分支的 `if` 裡呼叫 `textureSample`（會編譯失敗、整個畫面變黑）。
- 物件的名稱只寫在潛水日誌的 HTML 裡，指到物件時的提示直接拿那裡的內容。
- 藏寶圖只有一個視窗，換頁是把不是這一頁的 `[data-p]` 設成 `hidden`。樣式表有 `[hidden] { display: none !important }`。
- 開過的物件記在 `localStorage.fgOpen`（逗號隔開的 `IDS`），語言記在 `localStorage.fgLang`。
- 陰影只烘焙一次：箱蓋的影子停在載入時的狀態。
- 載入時的階段文字（Carving canyons… 等）不再顯示，固定顯示「正在下潛…」。
