# 素材庫

作品集網站使用的素材。原網站擷取下來的圖片在 `../original-site/assets/`。

原始高畫質影片放在 Google Drive（[素材資料夾](https://drive.google.com/drive/folders/13TOuc1BGub0lsLWP0pKrCcA46eHBNq5k)）。單支最大 233 MB，超過 GitHub 每個檔案 100 MB 的上限，所以倉庫裡只放網站用的壓縮版。

## 資料夾

| 資料夾 | 內容 | 規格 |
|---|---|---|
| `videos/` | 直接上傳的原檔 | — |
| `web/` | 網站播放用壓縮版 | 直式 720×1280、橫式 1280×720；H.264 + AAC；已最佳化串流（faststart） |
| `posters/` | 封面圖（取自影片 30% 處） | JPG，與 web 版同尺寸 |
| `previews/` | 6 秒靜音預覽，給作品卡片自動播放 | 直式 360 寬、橫式 640 寬，每支約 150–230 KB |
